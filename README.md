
## Ecommerce Application 

Welcome to the Ecommerce Application course! In this repository, we will guide you through the process of creating a complete, feature-rich ecommerce platform from scratch using ASP.NET Core API. You'll develop both the front-end and back-end, implementing essential features that every modern ecommerce app needs.
### Technologies
- Back-end:  ASP.NET CORE API 8, ASP.NET CORE MVC 8, C#, Jwt, AutoMapper, FluentValidator.
- Frond-end: Html, Css, JS, Bootstrap.
- DB: SQL Server, Redis, MongoDB
- Cloud: Azure Blob Storage
- Design Patterns and Rules: SOLID, Repository Pattern, Singleton Pattern, Factory Pattern, Clean Code, Clean Architecture
- More: RabbitMQ, Elasticsearch, Docker, ( gRPC, SingalR )


### Getting Started
- Visual Studio
- NET SDK
- SQL Server
- Azure Account

### Installation
Clone the Repository:

```bash
  git clone https://github.com/duonhungsw/Furniture.git
```
Navigate to the Project Directory:

```bash
  cd your-repo-name
```
Install Dependencies:
```bash
  dotnet restore
```

Set up appsettings:

- Update the appsettings.json with your SQL Server and Azure Blob connection string.
- Run the following command to apply migrations:
```bash
  dotnet ef database update
```
```bash
  Update-Database
```

### Running the Application
- Build and Run:
```bash
  dotnet run
```
